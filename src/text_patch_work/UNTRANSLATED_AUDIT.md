## A. 번역 금지 (크래시 위험) — 미번역이 정답 ⛔

아래 vsc들은 유닛/맵/지형을 로드·매칭하는 **내부 키·데이터·enum**입니다.
한글로 바꾸면 게임이 해당 리소스를 못 찾아 **유닛이 안 뜨거나 미션 진행이 정지**합니다
(이미 겪은 크래시와 동일 메커니즘).

| 그룹 | 파일 | 내용(=왜 위험한가) |
|---|---|---|
| 유닛 로스터/덱 | `Character/PbMode/*_units.vsc` (60여개) | 덱 구성 = 유닛 **내부 KEY**(ジム/ガンダム). 덱·미션·SPB가 이 이름으로 참조 |
| 맵 정의 | `Field/PbMode/Attribute/random_map*·singlemap*·vsmap*·testmap*·pbmap*·attr_map*` | 맵 크기·지형 정의(平地/山岳=데이터 키+번호)·좌표 |
| 맵 배치 | `Field/PbMode/Map/**/*.vsc`, `set_vs*`, `non_point*` | 유닛 배치 좌표·시작 유닛 키 |
| 지형 데이터 | `Field/PbMode/pbmode_attr.vsc` **col0 地形名称** | 지형 **KEY**. (col1 表示名称=표시명은 이미 번역됨 ✅) |
| 맵/상태 | `pbmode_map.vsc`, `pbmode_state.vsc` | 맵 데이터, 카메라 좌표(Pitch/Pos 등 수치) |
| 유닛 데이터 | `Unit/PbMode/pbmode_unit.vsc`, `Unit/AbMode/ユニットデータ.vsc` | 유닛명 KEY + 스탯 + enum(汎用/陸戦, グー/パー) + 모델파일 경로 |
| 무기 데이터 | `Unit/AbMode/武器データ.vsc` | 스탯·탄종·번호(표시명은 아래 B 참조) |
| 상성/보너스 | `Unit/AbMode/ab_bonus.vsc` | 유닛명 헤더(KEY) + 상성 수치표 |
| 카드 데이터 | `Card/PbMode/*.vsc` | 카드 데이터·키 |
| 사운드 | `Sound/volume.vsc`, `Kaw/capsule_box.vsc`, `Kaw/window.vsc` | SE/BGM 리스트·번호(비표시 내부설정) |
| 미션 데이터 | `Spb/ab_mission/ab_mission.vsc` **일부 열** | 파일럿/미션 번호, 시작유닛 키(표시열은 B 참조) |

> ⚠ 이 목록은 "번역 누락"이 아니라 **일부러 남긴 것**입니다. 건드리면 안 됩니다.

## B. 안전한 표시 텍스트 — 추가 번역 가능 ✅

순수 표시용(플레이어에게 보여주기만, 키로 참조 안 됨)이라 SPB 대사와 같은 방식으로 안전.

| 대상 | 파일 | 번역 가능 셀 | 유지할 키 |
|---|---|---|---|
| **도감 설명** | `Kaw/gallery.vsc` | **1210셀** (col1~8 유닛 설명문, 루비 포함) | col0 유닛명(170) = 조회 키, 유지 |
| **챌린지 미션** | `Spb/ab_mission/ab_mission.vsc` | **300셀** (타이틀·클리어조건·설명) | col7 시작유닛(100) = 키, 유지 |

두 파일 모두 SPB 대사와 동일한 루비 `|漢字(かな)` 표기라, 캐리어 인코딩·동일크기 주입으로
크래시 없이 번역 가능합니다. (도감 설명은 분량이 커 대사 재번역과 비슷한 작업량)

### 보류 권장 (표시일 수 있으나 참조 여부 미확정)
- `武器データ` **무기명**(약 800): 유닛 무기 목록에 표시될 수 있으나, 다른 곳에서 키로
  참조하는지 미확인. 크래시 이력을 감안해 **검증 전 보류**.
- `unit_names`(마스터 175): 이미 번역했으나 vsc 슬롯이 짧아 **오버플로로 미적용**.
  유닛명은 내부 키이기도 해 적용 시 위험 → 현 상태(미적용) 유지 권장.
